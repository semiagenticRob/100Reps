# Rep 018 — Stupid Simple Agentic CRM

**Status:** Dead
**Repo:** [semiagenticRob/stupid-simple-agentic-crm](https://github.com/semiagenticRob/stupid-simple-agentic-crm)

Lightweight agent-operated personal CRM inside a GitHub repo. YAML files are source of truth, CSV index is auto-generated, and the AI agent reads the README and operates the CRM by committing changes. Designed to be forked and immediately useful.

**Killed 2026-05-11:** HubSpot free tier with agent API access and crons solves the same problems with more functionality and no infrastructure to maintain. The locally-hosted approach was made redundant.
